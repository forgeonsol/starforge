# Запуск $FORGE на своём сервере — пошагово

Итог: сайт открывается по `https://ваш-домен`, сертификат продлевается сам, база ежедневно копируется, наружу открыты только порты 80 и 443.

## Что понадобится
- **VPS на Ubuntu 22.04 или 24.04.** Для старта хватит 1 ядра, 1 ГБ памяти и 10 ГБ диска. Подойдёт любой хостинг: Hetzner, DigitalOcean, Timeweb, Aeza и т. п.
- **Домен.** В его DNS нужна запись `A` на IP сервера, а если у сервера есть IPv6 — ещё и запись `AAAA`.
- **SSH-ключ на вашем компьютере.** Если его нет, создайте командой `ssh-keygen -t ed25519` и добавьте публичный ключ в панели хостинга при создании сервера.

## Шаг 1. Подготовить сервер (один раз)
```bash
ssh root@IP_СЕРВЕРА
git clone https://github.com/ВЛАДЕЛЕЦ/starforge.git && cd starforge
sudo bash infra/setup-ubuntu.sh --deploy-user forge
```
Скрипт настраивает:
- **Фаервол.** Открыты только SSH, 80 и 443.
- **fail2ban.** Блокирует перебор паролей по SSH.
- **Автообновления безопасности.**
- **Docker** с ограничением размера логов.
- **Пользователя `forge`** с вашим SSH-ключом.

Дальше:
1. В **новом** окне терминала проверьте, что входит `ssh forge@IP_СЕРВЕРА`.
2. Только после этого отключите вход под root и по паролю:
   ```bash
   sudo bash infra/setup-ubuntu.sh --deploy-user forge --harden-ssh
   ```
   Если SSH-ключа нет, скрипт пароль не отключит, поэтому запереть себя снаружи нельзя.

## Шаг 2. Указать домен
```bash
cd ~/starforge/infra      # или /root/starforge/infra, смотря куда клонировали
cp .env.example .env
nano .env
```
Впишите:
```
DOMAIN=ваш-домен.com
ACME_EMAIL=ваша@почта.com
```

## Шаг 3. Запустить
```bash
docker compose up -d --build
docker compose ps
```
Подождите, пока у `app` появится статус `healthy`.

Через минуту откройте `https://ваш-домен.com`. Если сертификат не выдался, посмотрите `docker compose logs caddy`. Почти всегда причина одна из двух: домен ещё не указывает на сервер или закрыт порт 80.

## Обновить сайт
```bash
bash ~/starforge/infra/deploy.sh
```
Скрипт сам сделает копию базы, скачает новый код, пересоберёт и перезапустит приложение и проверит, что оно поднялось.

## Резервные копии
- **На сервере.** База копируется раз в сутки, хранятся последние 14 копий. Но эти копии лежат на том же сервере.
- **На вашем компьютере.** Поэтому время от времени забирайте копию к себе:
  ```bash
  bash infra/backup-download.sh forge@IP_СЕРВЕРА ~/starforge-backups
  ```
- **Восстановление** описано в [DEPLOY.md](../../DEPLOY.md#backups).

## Как устроена защита
- **Вход без регистрации.** Игрок вводит позывной, сервер создаёт пилота и ставит cookie `__Host-forge_sid`. Cookie недоступна скриптам на странице (HttpOnly), передаётся только по HTTPS (Secure) и не уходит на запросы с чужих сайтов (SameSite).
  - Сам токен в базе не хранится, только его хэш.
  - Сессия живёт 180 дней и продлевается при каждом заходе.
  - Если игрок очистит cookie, доступ к этому пилоту пропадёт.
- **Чужие заголовки входа игнорируются.** Старый вход через ChatGPT опирался на заголовки хостинга. На своём сервере их мог бы подделать кто угодно, поэтому сервер их вырезает.
- **Защита от CSRF.** Любое изменение принимается только с вашего же сайта (проверка Origin) и только в формате JSON, тело запроса — до 16 КБ.
- **Позывные.** Ник уникален без учёта регистра. Ники вроде ADMIN, SUPPORT, OFFICIAL, FORGE заняты заранее, чтобы никто не выдавал себя за команду.
- **Лимиты:**
  - не больше 5 новых пилотов в час и 20 в сутки с одного IP;
  - не больше 60 забегов в час;
  - не больше 90 действий в минуту на игрока;
  - общий лимит запросов с одного IP.
- **Проверка забегов.** Невозможные результаты отклоняются и пишутся в журнал `security_events`. Забег нельзя отправить быстрее, чем его можно сыграть.
- **Магазин и рефералы.** Цены есть только на сервере, двойная покупка невозможна. Реферальный бонус платится один раз и только за настоящий первый забег длиной от минуты.
- **Заголовки страниц:**
  - строгая CSP без встроенных скриптов;
  - HSTS;
  - запрет встраивания в чужие сайты (frame);
  - nosniff, Referrer-Policy, Permissions-Policy.
- **Контейнер:**
  - запущен не от root;
  - файловая система только для чтения, писать можно только в `/data`;
  - все привилегии сняты;
  - выхода в интернет нет;
  - есть лимиты памяти и процессов.
- **Сервер.** Принимает только ваш домен, на запрос с чужим Host отвечает 421. Таймауты на медленные запросы, корректная остановка без потери данных.

## Ограничения
- **Подделка забега.** Очки считаются в браузере. Правдоподобно подделанный забег пройдёт проверку; полная защита — пересчёт забега на сервере по записи ввода.
- **DDoS.** От больших атак защищает уровень сети: Cloudflare-прокси или защита хостинга. Как включить Cloudflare правильно, описано в [DEPLOY.md](../../DEPLOY.md#behind-cloudflare).
- **Аккаунты привязаны к браузеру.** Чтобы играть с другого устройства, нужен перенос аккаунта, например по коду восстановления. Пока его нет.
