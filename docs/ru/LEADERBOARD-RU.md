# $FORGE: лидерборд и безопасность (без кошельков)

## Что сделано

### Лидерборд
- **Где показывается:**
  - на лендинге — экран «Leaderboard» с Top-10, помещается в один экран (на телефоне 7 строк);
  - в игре — вкладка LEADERBOARD: полный список, вкладки Top 10 / Top 50 / All и поиск по нику.
- **Строка:** место, аватар (генерируется из ника), ник, лучший результат, изменение позиции.
- **Реальные игроки** — это существующие игровые аккаунты (вход через ChatGPT). Их забеги уже приходят на `POST /api/score`, и лидерборд берёт лучший забег каждого игрока из `arena_scores`.
  - Список приходит с `GET /api/leaderboard` и обновляется раз в 20 секунд без перезагрузки; при ошибке опрос становится реже.
  - Реальные игроки отмечены ✓, своя строка — меткой YOU.
  - Если игрок не вошёл, его лучший результат с этого устройства показывается строкой «YOU · THIS DEVICE».
- **Демо-профили** ранжируются вперемешку с реальными:
  - на каждой строке метка DEMO, в шапке — «Includes demo profiles»;
  - генерируются в браузере (`public/leaderboard.js`) и никогда не попадают в базу;
  - двигаются медленно: каждые 7–15 секунд меняются очки 1–2 профилей, раз в 1–2 минуты появляется новичок.
- **Анимация:** строки плавно переезжают (transform), подъём подсвечивается зелёным, падение красным, числа меняются плавно. В DOM только видимые строки, все числа анимирует один общий цикл. Поддерживается `prefers-reduced-motion`.
- **Статичная копия (артефакт)** без сервера: демо-профили плюс ваш лучший результат с этого устройства.

### API
| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/leaderboard?scope=all\|week&limit=&q=` | рейтинг: серверная сортировка, лимит до 500, поиск по нику |
| POST | `/api/score` | отправка забега (как и раньше, через ChatGPT-вход) |

Логика лежит в `lib/forge-server.ts` и не зависит от фреймворка; `app/api/leaderboard/route.ts` — тонкая обёртка.
Маршруты входа кошельком (`/api/auth`, `/api/me`, `/api/run`) удалены.

### База данных
Миграция `drizzle/0005_board_security.sql` (уже в журнале):
- `rate_limits` — счётчики ограничений частоты;
- `security_events` (+ индекс) — журнал подозрительных действий;
- индекс `arena_scores_player` для быстрого рейтинга.

## Безопасность
- **Никаких внутренних id наружу:** у строки есть только непрозрачный ключ `sha256("forge-board:" + id)` (16 символов).
- **Ограничение частоты:** `/api/leaderboard` — 120 запросов в минуту с IP; `/api/score` — 60 забегов в час с IP.
- **Проверка правдоподобия забега:** счёт, уровень, боссы и убийства сверяются с длительностью. Невозможные забеги отклоняются и пишутся в `security_events`.
- **Заголовки:** ответы API сами ставят `nosniff`, HSTS, `no-store` и др. Для статики в `public/_headers` заданы CSP (`script-src 'self'`, встроенные скрипты вынесены в `storage-shim.js` и `theme-init.js`), HSTS, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, правила кэша.

Автотесты: `node scripts/test-forge-server.mjs` — 16 проверок на настоящих миграциях в SQLite (порядок, изменение места, «новый», своя строка, отсутствие id в ответе, стабильные ключи, поиск, лимиты, заголовки, rate limit, правдоподобие, журнал). Все проходят.

## Как выкатить
1. `corepack pnpm install`, затем `corepack pnpm build`. Здесь собрать не удалось — нет доступа к npm-реестру. Серверный код проверен тестами и строгой проверкой типов, полную сборку нужно сделать у вас.
2. Применить миграцию `0005_board_security` так же, как предыдущие.
3. Проверить `public/online-config.js`: здесь `window.FORGE_ONLINE = true`, в статичном превью — `false`.
4. Локальная проверка: `COOKIE_SECURE=0 DEV_SEED=1 node --experimental-strip-types server/server.mjs` и открыть http://127.0.0.1:3000.

> Запуск на своём сервере и вход без регистрации описаны в [VPS-RU.md](VPS-RU.md). Разделы ниже про вход через ChatGPT относятся только к исходному хостингу.

## Ограничения
- **Подделка забега.** Очки считаются в браузере. Сервер отсекает невозможные результаты и частые отправки, но правдоподобную подделку отправить можно. Полная защита — серверная проверка повтора забега по seed и записи ввода.
- **Снимок схемы drizzle** для 0005 не сгенерирован (нет drizzle-kit здесь). Перед следующим `pnpm db:generate` выполните `drizzle-kit generate` и проверьте, что дубликатов таблиц нет.
- **`_headers`** работает на Cloudflare static assets; на другом хостинге задайте заголовки в его настройках.
- **Rate limit** в D1 — фиксированное окно. От ботов и DDoS нужен Cloudflare WAF или Turnstile.
