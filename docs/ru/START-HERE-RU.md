# Starforge — запуск и редактирование

## Что внутри

Это полный исходный проект сайта и игры: интерфейс, арена, кампания пилота, игровые изображения, API, настройки сборки и файл фиксации зависимостей.

Основные файлы:

- `public/index.html`, `public/landing.js` — лендинг (`app/page.tsx` только перенаправляет на него).
- `app/globals.css`, `app/landing.css` — стили.
- `public/game.html`, `public/game.js` — игра «Арена».
- `public/game.css` — единая дизайн-система игры (светлая и тёмная тема).
- `public/sfx.js` — синтезированные звуки (без аудиофайлов), общие для Арены и Кампании.
- `AUDIT-RU.md` — отчёт аудита и список изменений.
- `public/pilot-campaign.js` — кампания пилота.
- `public/assets/` — изображения кораблей, пилотов, врагов, карт и модулей.
- `app/api/` — API профиля, таблицы лидеров, рейдов и результатов.

## Запуск на компьютере

Нужны Node.js `22.13` или новее и pnpm `11.25.0` (его можно запустить через Corepack).

```sh
corepack pnpm install
corepack pnpm dev
```

Открой адрес, который появится в терминале (обычно `http://localhost:5173`). После изменения файлов страница обновляется автоматически.

Для production-сборки:

```sh
corepack pnpm build
```

## Как менять игру

- Правь `public/game.js` для механики арены.
- Правь `public/pilot-campaign.js` для уровней и механики кампании пилота.
- Меняй или добавляй изображения в `public/assets/` и `public/`.
- Правь `app/page.tsx` и CSS-файлы для интерфейса сайта.

Архив содержит исходники, а не установленную папку зависимостей: установка выполняется командой `corepack pnpm install`.
